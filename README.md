# POOSD Contact Manager Team 6

## A Personal Contact Manager web application.

This project allows each user to create an account, log in, and manage their private contacts independently of other users. Once user is logged in with a valid account, they can add, edit, delete, and search for contacts. 

Additional information:
- Utilizes the LAMP stack (Linux, Apache, MySQL, PHP)
- Hosted on Digital Ocean
- Implements a REST-style API
